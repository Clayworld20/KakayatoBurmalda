# 🤖 AI Agent Manager

Простое десктопное приложение для Windows, которое помогает управлять
нейросетями (локальными и облачными) и роботом-помощником, работающим
с вашим экраном, мышкой и клавиатурой.

Написано **полностью на Python** — никаких сложных технологий.
Каждая строчка кода снабжена комментарием на русском языке.

---

## 🚀 Как запустить (2 простых шага)

### 1. Установите Python (если ещё нет)
Скачайте с сайта [python.org/downloads](https://www.python.org/downloads/)
и при установке **обязательно поставьте галочку "Add Python to PATH"**.

### 2. Запустите программу
Дважды щёлкните по файлу `main.py` — или введите в командной строке:

```
python main.py
```

**Больше ничего устанавливать не нужно!** При первом запуске программа сама
скачает все библиотеки (в консоли появится надпись «Устанавливаю необходимые
компоненты для первого запуска, подождите...») и затем откроет окно. 🎉

---

## 📥 Установка одним установщиком (для обычных пользователей)

Python и командная строка не нужны вообще! Скачайте готовый установщик:

1. Откройте раздел **Releases** в репозитории (правая колонка главной страницы).
2. Скачайте файл **AI-Agent-Manager-Setup.exe** из последнего релиза.
3. Запустите его двойным кликом — дальше всё автоматически: установщик сам
   поставит Python (если нет), скачает библиотеки готовыми сборками
   (без компиляции и зависаний) и создаст значок на рабочем столе.

> **Как установщик обновляется:** GitHub Actions собирает его сам.
> Достаточно выставить тег (Code → Releases → Draft a new release →
> создать тег вида `v1.0.0` → Publish) — через несколько минут готовый
> Setup.exe появится в этом релизе. Конфиги: `agent_manager_setup.iss`
> и `.github/workflows/manager_release.yml`.

## 📦 Сборка в один exe-файл (для раздачи друзьям)

Хотите поделиться программой с человеком, у которого нет Python?
Один раз соберите exe — в папке программы выполните:

```
python build.py
```

Скрипт сам установит сборщик PyInstaller (если его нет) и через 1–3 минуты
положит готовый файл `dist/AI-Agent-Manager.exe`. Его можно запускать двойным
кликом на любом компьютере с Windows — без Python и без настроек.

> Первый запуск exe может занять 10–20 секунд, а антивирус может спросить
> разрешение — это обычное поведение для файлов PyInstaller.

## ⏹ Аварийный стоп робота

Пока робот работает, нажмите **Esc** в любой момент — он мгновенно
остановится, даже если окно программы свернуто. Подстраховка №2:
быстро уведите мышку в угол экрана (встроенная защита pyautogui).

## 📁 Из чего состоит программа

| Файл                       | Что это                                                    |
|----------------------------|------------------------------------------------------------|
| `main.py`                  | Запуск: автоустановка библиотек, окно, меню, вкладки        |
| `theme.py`                 | Все цвета и шрифты (хотите перекрасить — меняйте тут)       |
| `pages/home_page.py`       | Вкладка «Главная» — статус системы и индикаторы нагрузки    |
| `pages/brain_page.py`      | Вкладка «Мозг» — скачивание моделей и API-ключи             |
| `pages/robot_page.py`      | Вкладка «Робот» — включение агента и лог его действий       |
| `services/netcheck.py`     | Проверка интернета и локальной нейросети Ollama             |
| `services/config_manager.py` | Сохранение ключей в файл config.json                      |
| `services/cloud_api.py`    | Запросы к Claude и OpenAI (проверка ключей, чат, скриншоты) |
| `services/ollama_client.py`| Скачивание моделей и чат с локальными моделями              |
| `services/agent_runtime.py`| Двигатель робота: мозг + скриншоты + мышь + стоп-кран Esc   |
| `build.py`                 | Сборщик программы в один exe-файл (PyInstaller)             |
