# 🤖 AI Agent Manager

Простое десктопное приложение для Windows, которое помогает управлять
нейросетями (локальными и облачными) и роботом-помощником, работающим
с вашим экраном, мышкой и клавиатурой.

Написано **полностью на Python** — никаких сложных технологий.
Каждая строчка кода снабжена комментарием на русском языке.

---

## 🚀 Как запустить (2 простых шага)

### 1. Установите Python (если ещё нет)
Скачайте с сайта [python.org/downloads](https://www.python.org/downloads/)
и при установке **обязательно поставьте галочку "Add Python to PATH"**.

### 2. Запустите программу
Дважды щёлкните по файлу `main.py` — или введите в командной строке:

```
python main.py
```

**Больше ничего устанавливать не нужно!** При первом запуске программа сама
скачает все библиотеки (в консоли появится надпись «Устанавливаю необходимые
компоненты для первого запуска, подождите...») и затем откроет окно. 🎉

---

## 📁 Из чего состоит программа

| Файл                       | Что это                                                    |
|----------------------------|------------------------------------------------------------|
| `main.py`                  | Запуск: автоустановка библиотек, окно, меню, вкладки        |
| `theme.py`                 | Все цвета и шрифты (хотите перекрасить — меняйте тут)       |
| `pages/home_page.py`       | Вкладка «Главная» — статус системы и индикаторы нагрузки    |
| `pages/brain_page.py`      | Вкладка «Мозг» — управление нейросетями                     |
| `pages/robot_page.py`      | Вкладка «Робот» — агент-помощник                            |
| `services/netcheck.py`     | Проверка интернета и локальной нейросети Ollama             |
