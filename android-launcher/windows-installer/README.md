# Оконный установщик Windows

Пользователю нужен готовый ZIP, а не исходники или PowerShell. В комплекте EXE с подсистемой Windows GUI, APK и официальный ADB. Python не требуется, дополнительных установок библиотек нет; нужен .NET Framework 4.7.2+ (обычно присутствует на обновлённых Windows 10/11). Права администратора не запрашиваются.

`build.ps1` — скрипт для разработчика/CI: принимает готовый APK и каталог официальных Platform Tools, компилирует C# через системный csc и формирует ZIP. Контрольные суммы всех файлов зависимостей вшиваются в EXE; код сопряжения не сохраняется и не показывается в диагностике. Ни одна операция не отключает штатный лаунчер и не меняет назначение HOME.

GitHub Actions собирает APK, запускает Lint, компилирует и выполняет `InstallerTests.cs`, затем формирует артефакт. Релизы и публикация облачного окружения не выполняются. Комплект использует отладочную подпись APK: повторная сборка на другом runner может требовать удаления предыдущего MiLite TV из-за другой подписи. Перед стабильными обновлениями нужна отдельная релизная подпись.

Проверено локально: C# 5 / .NET Framework 4.7.2 cross-compilation в Windows GUI EXE; 42 проверки логики на .NET 8 в Linux, включая чтение stdout/stderr, код возврата и остановку процесса по тайм-ауту. Графическое окно на Windows и взаимодействие с настоящим ТВ не проверены. Результат Windows CI следует проверять отдельно по запуску Actions.
