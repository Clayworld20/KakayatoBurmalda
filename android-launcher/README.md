# MiLite TV · 0.1.0

Лёгкий экспериментальный домашний экран Android TV для Xiaomi L43R5-5ARUM. Минимальная версия Android — 6.0 (API 23); фактическая версия и совместимость прошивки телевизора ещё не проверены. Нет рекламных лент, аналитики, WebView, сетевых запросов и фоновых сервисов. Нативные Java / Android Views без сторонних библиотек. Дизайн вдохновлён простотой Apple TV, без использования его ресурсов.

## Возможности

- Все приложения с Android TV / Android launcher activity; навигация стрелками и ОК.
- Избранное через верхнюю кнопку или удержание ОК на карточке. Хранится локально.
- Плитка VPN ищет v2rayTun среди установленных приложений. Если не находит — предлагает выбрать приложение вручную и запоминает выбор.
- Плитка открывает приложение, а не переключает соединение. Интеграция для прямого включения v2rayTun пока не подтверждена.
- Индикатор показывает наличие VPN-транспорта по данным Android: это не доказательство работы конкретного провайдера, туннеля или доступа в Интернет.
- Часы обновляются только пока лаунчер открыт; нет загрузки постеров или рекомендаций.

## Установка с Windows через PowerShell

1. Скачайте официальные [Android SDK Platform Tools для Windows](https://dl.google.com/android/repository/platform-tools-latest-windows.zip) и распакуйте архив, например в `C:\platform-tools`.
2. Скопируйте `MiLite-TV-0.1.0-debug.apk` в эту папку. Это тестовый APK с отладочной подписью, не релизная сборка.
3. На телевизоре откройте «Об устройстве» и нажмите на номер сборки несколько раз до появления режима разработчика. В параметрах разработчика включите отладку ADB. Названия и доступность пунктов зависят от прошивки. Если есть отдельная «Отладка по сети» — включите её.
4. ПК и телевизор должны быть в одной локальной сети. Узнайте IP телевизора в настройках сети. В PowerShell откройте папку Platform Tools:

```powershell
cd C:\platform-tools
.\adb.exe connect 192.168.1.50:5555
.\adb.exe devices
```

Замените пример IP на адрес ТВ; порт 5555 подходит лишь для старого режима сетевого ADB. Подтвердите разрешение на экране ТВ. Если устройство указано как `unauthorized`, установку пока не запускайте. На новых версиях с «Беспроводной отладкой» используйте показанные на ТВ порты и `adb pair IP:PORT`, затем `adb connect IP:PORT` — они могут отличаться от 5555. Если отладка по сети отсутствует, сначала уточните доступные настройки прошивки. Не подключайте обычные USB-A порты телевизора и ПК кабелем A–A.

Если подключено несколько Android-устройств, добавляйте `-s IP:PORT` после `adb.exe` во всех командах для ТВ.

5. Запишите штатный HOME-компонент для возможного возврата:

```powershell
.\adb.exe shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

Если команда возвращает системное окно выбора, а не конкретный лаунчер, сохраните названия текущих приложений домашнего экрана через настройки ТВ.

6. Установите и откройте пробную версию:

```powershell
.\adb.exe install -r .\MiLite-TV-0.1.0-debug.apk
.\adb.exe shell am start -n dev.milite.launcher/.MainActivity
```

Сначала проверьте экран, кнопки пульта, запуск приложений и плитку VPN. Удержание ОК добавляет приложение в избранное. На странице VPN нажмите «Назад», чтобы вернуться и проверить индикатор.

7. Только после проверки нажмите Home. Если появится выбор, выберите MiLite TV и «Всегда». Либо откройте системные настройки приложений по умолчанию → домашний экран. Некоторые прошивки Xiaomi не позволяют изменить HOME стандартным способом. Установка APK сама по себе не гарантирует переназначение кнопки Home.

Не удаляйте и не отключайте штатный лаунчер / PatchWall. Никаких команд очистки системных пакетов для этой версии не требуется.

## Возврат

Выберите прежний домашний экран в системных настройках. Если настройки доступны только через ADB:

```powershell
.\adb.exe shell am start -a android.settings.SETTINGS
```

При наличии записанного HOME-компонента на поддерживаемых версиях Android можно вернуть его командой `adb shell cmd package set-home-activity ИСХОДНЫЙ_ПАКЕТ/ИСХОДНАЯ_ACTIVITY`. Затем удалите тестовую версию:

```powershell
.\adb.exe uninstall dev.milite.launcher
```

После проверки выключите отладку на телевизоре. Root для приложения не нужен.

## Сборка

Откройте проект в Android Studio, используйте JDK 17 или 21 и Android SDK Platform 35. В Android Studio подтвердите лицензии необходимых SDK. `local.properties` создаётся локально, в архив исходников не входит. В Windows:

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Проект использует compile/target SDK 35 и min SDK 23; это sideload-прототип, не готовая публикация Google Play. Релизная подпись и обновления — отдельный этап.

## Проверка на телевизоре

- Открываются все три ряда управления и карточки; переходы стрелками и удержание ОК работают.
- Избранное сохраняется после закрытия/повторного открытия.
- Приложения запускаются, «Назад» возвращает фокус к VPN, Home открывает выбранный домашний экран.
- v2rayTun открывается; при ручном включении/отключении VPN индикатор меняется после возврата.
- Сравните время появления карточек и задержку перемещения фокуса со штатным экраном на одном ТВ.

Сборка и Android Lint не заменяют испытание на устройстве. Устранение тормозов пока не измерено. Видео-приложения и системные фоновые процессы этот лаунчер не модифицирует.
